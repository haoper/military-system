⚙️ Supabase 配置

Supabase 是开源的 Firebase 替代品，功能强大且完全免费！配置只需3分钟。

📝 配置步骤：
  1. 访问 Supabase 官网 注册账号（免费）
  2. 创建新项目（选择离您最近的区域）
  3. 进入项目设置 → API
  4. 复制 Project URL 和 anon public key
  5. 在数据库中创建表：military_servers

💡 提示：配置信息将保存在浏览器本地。Supabase 完全免费，每月提供 500MB 数据库、1GB 文件存储、2GB 带宽。详细配置教程请查看 "Supabase配置指南.md"。
